Chaos Rings II (CR2-U): your own fonts, if you want them - .ttf, .otf or .ttc files put here.

Leave this folder empty and the game uses its own font: the Android release's (TypeBank Gothic, read
out of its APK) or the Vita's, else a system font (the iPad's copy has none of its own), with a
Japanese / Chinese / Korean font of the system's behind it for the characters it lacks.

A font here takes the place of one of those:
- a font without Japanese / Chinese / Korean characters takes the game's font's place (all the text);
- a font with them goes before the system's for the characters the game's font lacks - one with
  "bold" in its file name first, as the system's used are the bold ones.
Several of a kind: the first by file name. A font far wider than the game's can run long lines off
the message window. --font, CR2_FONT and CR2_FONT_FALLBACK still come first.
The log (cr2view.log in the profile folder) names the font/ files it used.
